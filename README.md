# AI and the Future of the UCC Website

A presentation by **Dr. Kara Hosford**

## Overview

This repository contains a presentation exploring AI integration strategies for the UCC website, including considerations for accessibility, user experience, and international audiences.

## Presentation Files

- **web_presentation.html** - The main presentation (compiled from Marp)
- **web_presentation.md** - Presentation source markdown
- **html/sim.html** - Additional resources
- **images/** - Presentation assets

## Viewing the Presentation

Visit the GitHub Pages site to view the presentation:
- **Main presentation**: [web_presentation.html](web_presentation.html)

## Building from Source

To rebuild the HTML from the markdown source, you can use [Marp](https://marp.app/):

```bash
marp web_presentation.md -o web_presentation.html
```
